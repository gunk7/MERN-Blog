## 📖 **Project Overview**

**Wavelog** is a modern, feature-rich blogging platform that combines traditional blog publishing with cutting-edge AI capabilities. It's designed for content creators who want to write, publish, monetize, and grow their audience with AI-assisted writing tools.

### **Core Value Proposition**
- ✍️ **Write smarter**: AI-powered writing assistance (tone adjustment, rephrasing, clarity improvement)
- 📈 **Grow faster**: Built-in social features (followers, comments, recommendations)
- 💰 **Monetize easily**: Integrated subscription plans, flexible payment processing
- 🤖 **AI companion**: Conversational AI for research, ideation, and content improvement
- 📊 **Understand readers**: Analytics dashboard to track engagement

---

## 🏗️ **Technology Stack**

### **Frontend**
- **Framework**: React 18.x with Vite
- **State Management**: Redux Toolkit
- **Styling**: CSS, Tailwind CSS (implied)
- **Rich Text Editor**: Custom markdown/HTML editor with toolbar
- **Authentication**: JWT + Google OAuth 2.0
- **API Client**: Axios with interceptors
- **Notifications**: React Toastify
- **Routing**: React Router v6

### **Backend**
- **Runtime**: Node.js
- **Framework**: Express.js 5.x
- **Database**: MongoDB with Mongoose ODM
- **Authentication**: JWT, Passport.js (Google OAuth)
- **Payment Processing**: Stripe API
- **AI Integration**: Google Generative AI (Gemini 3.1)
- **Email**: Nodemailer with Gmail SMTP
- **File Upload**: Multer
- **Background Tasks**: Node-cron
- **Logging**: Winston
- **Validation**: Joi schemas

### **Admin Panel**
- **Framework**: React 18.x with Vite
- **Purpose**: Content moderation, user management, analytics, plan management
- **Same stack as frontend** (independent SPA)

### **Infrastructure**
- **Hosting**: Self-hosted or cloud (AWS/GCP/Azure)
- **Database**: MongoDB (local/Atlas)
- **File Storage**: Server filesystem (uploads/)
- **Email**: Gmail SMTP
- **Payment Gateway**: Stripe (primary), Razorpay (mentioned in code)
- **AI API**: Google Generative AI

## 🎯 **Main Features & Functionality**

### **1. 🔐 Authentication & User Management**

#### **Features**:
- **Email/Password Signup**
  - User registration with email verification (OTP)
  - Password hashing with bcrypt
  - Email OTP expiration validation
  
- **Google OAuth Integration**
  - One-click login with Google
  - Automatic account creation/linking
  - Profile data sync (name, photo)
  
- **Multi-Device Authentication**
  - Separate JWT refresh token per device
  - Logout from specific device or all devices
  - Token rotation on refresh
  
- **Password Management**
  - Forgot password flow (email-based)
  - Password reset with token validation
  - Change password with OTP verification

- **User Profiles**
  - Profile picture upload
  - Bio, first name, last name
  - Country, gender
  - Public profile viewing
  - Follower/following counts

**Technical Details**:
- JWT tokens: AccessToken (15 min) + RefreshToken (7 days)
- Password reset tokens expire in 15 minutes
- OTP expires in 10 minutes
- User has array of refresh tokens (one per device)

### **5. 🤖 AI Features (Token-Limited)**

#### **Core AI Capabilities**:

**1. AI Chat (Conversational)**
- Multi-turn conversations with context
- Rate limited: 15 requests per minute
- Use cases: Research, brainstorming, Q&A
- Token usage tracked and limited by plan

**2. Writing Assistant**
- **Improve Clarity**: Simplify complex sentences
- **Rephrase**: Rewrite content in different way
- **Change Tone**: 5 options
  - Formal (professional, business tone)
  - Casual (conversational, friendly)
  - Confident (assertive, strong)
  - Friendly (warm, approachable)
  - Professional (corporate, structured)

**3. Auto Tag Generation**
- Analyzes blog content
- Generates 5-10 relevant tags
- Helps with blog discoverability

**4. Content Summary Generator**
- Creates bullet-point summaries
- Markdown formatted
- Helps readers get quick insights

#### **Token System**:
- **Base Plan Tokens**: 50-500 per month (depends on plan)
- **Addon Tokens**: Purchase extra tokens (100/1000/5000 token packs)
- **Token Counting**: ~1 token per 4 characters
- **Usage Tracking**: Monthly reset on subscription renewal date
- **Enforcement**: Returns 429 error when limit reached
- **Addon Fallback**: Addon tokens consumed first if available

#### **Rate Limiting**:
- 15 API calls per minute per user
- Returns 429 Too Many Requests when exceeded

**Technical Details**:
- Gemini 3.1 API for generation
- Middleware: `checkUsageLimit` validates tokens
- Models: `UsageLog`, `Message`, `Chat` for tracking
- Token estimation: `text.length / 4`

### **6. 💳 Subscription & Monetization**

#### **Subscription Plans**:

| Feature | Free | Pro | Premium |
|---------|------|-----|---------|
| **Price** | $0 | $4.99/mo | $9.99/mo |
| **Blogs** | Unlimited | Unlimited | Unlimited |
| **AI Chat** | No | 100 tokens | 500 tokens |
| **Writing Assist** | No | Yes | Yes |
| **Tag Generation** | No | Yes | Yes |
| **Summary** | No | Yes | Yes |
| **Analytics** | No | Yes | Yes |
| **Addon Tokens** | No | Yes | Yes |

#### **Subscription Lifecycle**:
1. **Selection**: User chooses plan or free tier
2. **Checkout**: (Paid plans) Stripe checkout session
3. **Payment**: Card processing by Stripe
4. **Activation**: Subscription created (active or trialing)
5. **Renewal**: Auto-renew monthly (configurable)
6. **Cancellation**: User can cancel anytime
7. **Refund**: 14-day money-back guarantee

#### **Payment Processing**:
- **Provider**: Stripe (primary), Razorpay (supported)
- **Webhook Events**:
  - `checkout.session.completed`: Create subscription
  - `customer.subscription.updated`: Plan change
  - `charge.refunded`: Process refunds
  
- **Invoice Generation**:
  - Auto-generated invoice ID: `WL-YYYY-XXXX` (e.g., WL-2024-0001)
  - PDF invoices stored in `uploads/invoices/`
  - Accessible to users and admins
  - Tax-ready format

#### **Addon Token Purchase**:
- Purchase packs: 100, 1000, 5000 tokens
- One-time payment (not recurring)
- Consumed per-request (alongside base tokens)
- Purchase history tracked in `AddonPurchase` model

#### **Refund Requests**:
- User can request refund within 14 days
- Admin reviews and approves/rejects
- Approved refunds processed through Stripe
- Reason and notes tracked

**Technical Details**:
- Models: `Plan`, `Subscription`, `Transaction`, `Invoice`, `AddonPurchase`, `RefundRequest`
- Webhook signature verification (STRIPE_WEBHOOK_SECRET)
- Subscription states: `trialing`, `active`, `past_due`, `cancelled`, `expired`
- Auto-renewal toggle per subscription

### **Data Flow Examples**:

#### **Blog Creation Flow**:
1. User fills editor, uploads cover
2. Frontend sends POST `/api/blogs` with multipart/form-data
3. Multer middleware validates and stores cover image
4. Controller validates blog data with Joi schema
5. Create Blog document in MongoDB
6. Return created blog with image URL
7. If AI tags enabled: Generate tags via Gemini
8. User sees success toast

#### **Comment & Notification Flow**:
1. User writes comment, submits
2. Frontend sends POST `/api/comments`
3. Controller validates and creates Comment document
4. Controller creates Notification for blog author
5. (Future) Email notification sent
6. Frontend updates UI with new comment
7. Blog author sees badge count +1

#### **Subscription & Payment Flow**:
1. User selects plan, clicks "Subscribe"
2. Frontend calls POST `/api/subscription/checkout`
3. Backend creates Stripe checkout session
4. Redirects to Stripe hosted checkout
5. User enters card details, completes payment
6. Stripe webhook: checkout.session.completed
7. Backend creates Subscription document
8. Resets usage log, creates invoice
9. Sends confirmation email
10. User redirected to success page

#### **AI Request Flow**:
1. User sends message in AI chat
2. Frontend calls POST `/api/chat/message`
3. Middleware checks usage limit: `checkUsageLimit`
4. If tokens available:
   - Call Gemini API with message
   - Count tokens in response
   - Store message in `Message` model
   - Deduct from `UsageLog`
   - Return response
5. If tokens insufficient:
   - Return 429 + token purchase prompt

- `usagelogs`: Monthly token consumption
